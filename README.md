# La discothèque de Hugo

Une discothèque de vinyles en Cover Flow 3D : les pochettes défilent, le vinyle sort de son carton au survol, et chaque disque s'ouvre sur sa fiche (date, lieu d'enregistrement, compositeurs, crédits, anecdotes, faces A/B).

- **Écoute** : extraits de 30 s et lecteur complet Deezer (morceaux entiers si tu es connecté à Deezer).
- **Import** : ta collection Discogs, avec ton pseudo et ton jeton personnel (créé sur https://www.discogs.com/settings/developers). Le jeton reste dans ton navigateur.

## Utilisation

Ouvre `index.html` dans ton navigateur, ou active GitHub Pages (Settings → Pages → branche `main`, dossier racine) pour l'avoir en ligne.

Pour ajouter des disques à la main, complète la liste `DISQUES` dans `index.html`.
